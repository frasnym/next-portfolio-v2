# FrasNym's Portfolio Site

A portfolio website to introduce myself to the world 👋. Visit [frasnym.tech](https://frasnym.tech).

## Features

- Written in TypeScript
- Built with Next.js 16
- Styled with Tailwind CSS
- Deployed on Vercel
- Docker support for development

## Requirements

Node.js 20.9 or newer (22 recommended).

## Getting started

```bash
npm install
npm run dev
```

Or with Docker Compose:

```bash
docker compose up
```

## Checks

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
